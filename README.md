# Weather App


A responsive weather application built with React and TypeScript using real-time weather data.

## Live Demo

**[View Website](https://hosseinnaseran.github.io/weather)**

## Preview



## Features

- Search weather by city
- Real-time weather data
- Temperature
- Humidity
- Wind speed
- Responsive layout

## Tech Stack

- React
- TypeScript
- CSS3
- Vite
- OpenWeather API

## API

This project uses the OpenWeather API to fetch real-time weather information.

## Getting Started

```bash
git clone https://github.com/HosseinNaseran/weather.git

cd weather

npm install

npm run dev
```
